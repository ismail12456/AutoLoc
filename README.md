# AutoLoc

## Description
AutoLoc est une plateforme de gestion de location de véhicules multi-agences.

## Objectifs
- Gérer les véhicules
- Gérer les clients
- Gérer les agences
- Gérer les locations
- Centraliser les informations entre plusieurs agences

## Acteurs
- Client
- Agent d'agence
- Responsable d'agence / Manager
- Administrateur

## Cas d'utilisation principaux
- Consulter les véhicules disponibles
- Effectuer une demande de location
- Gérer les clients
- Gérer les véhicules
- Gérer les locations
- Gérer les agences
- Administrer la plateforme
